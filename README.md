# Car Rental Booking Automation

An automated workflow for handling car rental booking requests received by email.

The system extracts the main booking details from each email, including the customer's name, email, phone number, pickup and return dates, and car category. The information is then saved to Google Sheets, while AI generates an appropriate reply based on the information provided and identifies any missing details.

The goal is to reduce manual work, keep booking requests organized, and provide customers with a quick and consistent response.
